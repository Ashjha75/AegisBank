AegisBank should feel like a serious financial product: **precise, calm, trustworthy**. One light theme -
pure white pages, near-black **ink** for text and primary actions, hairline grey borders, and a single
**deep green** used sparingly for links, focus, selected states and the logo. Borders separate things;
shadows only lift what floats (menus, dialogs). No gradients, glows or decorative illustrations.

These docs use a warm **paper** variant of the same tokens for comfortable long reading. Component previews
switch back to the real white site surfaces, so what you see there is what customers will see.

Everything below is rendered from `src/styles/tokens.css` and `src/styles/docs-theme.css`.

## Colour

Components use **semantic** tokens (what a colour means), never the raw scales. `pnpm tokens:check` verifies
WCAG AA contrast for every text/background pair in both the site and the docs theme.

### shadcn/ui compatible

The Tailwind theme also maps shadcn's token names (`card`, `popover`, `muted`, `accent`, `destructive`,
`sidebar-*`), so a component added with `pnpm dlx shadcn@latest add <name>` picks up the AegisBank look
without edits. Note the meaning of two names:

| Class | Means here |
| --- | --- |
| `bg-accent` | Hovered / highlighted item background (shadcn's meaning) |
| `text-brand`, `bg-brand` | The deep green brand colour |

## Typography

One family, **IBM Plex**, with a technical, institutional character:

| Font | Used for | Weights |
| --- | --- | --- |
| **IBM Plex Sans** (`font-sans`, `font-display`) | Everything: headings at 500 with tight tracking, UI at 400-600 | 400, 500, 600 |
| **IBM Plex Mono** (`font-mono`) | References, IDs, account numbers in detail views, code | 400, 500 |

Money always uses tabular numbers (`numeric` class or the `<Amount>` component) so digits line up in columns.

## Icons

Two libraries, each with a job:

- **[Lucide](https://lucide.dev)** - every icon in the product UI (buttons, navigation, forms). 16 px in dense UI,
  20 px in navigation; stroke 1.75 for feature icons. Decorative icons get `aria-hidden`; icon-only buttons need an
  `aria-label`.
- **[Phosphor](https://phosphoricons.com)** - docs, diagrams and feature illustrations. Six weights, strong
  banking and engineering coverage. In MDX: <Ph name="Vault" /> `<Ph name="Vault" />`,
  <Ph name="Database" weight="duotone" className="text-brand" /> `<Ph name="Database" weight="duotone" />`.

## Shape, spacing, elevation

- **Radius**: crisp. `sm` 4 px (badges, checkboxes) · `md` **6 px** (buttons, inputs, cards, menus) · `lg` 8 px
  (dialogs) · `xl` 12 px (rare: hero frames). Only avatars, dots and switches are round.
- **Spacing**: 4 px grid. Common steps: 8, 12, 16, 24, 32, 48, 64.
- **Elevation**: cards and tables use a 1 px border. `shadow-xs` on controls, `shadow-md` on menus and popovers,
  `shadow-lg` on dialogs and sheets only.

## Motion

Quiet and precise: things move only to explain what changed.

| Token | Duration | Used for |
| --- | --- | --- |
| `duration-instant` | 80 ms | Press feedback (buttons scale to 98.5 %) |
| `duration-fast` | 140 ms | Hover, colour changes |
| `duration-base` | 200 ms | Popovers, tooltips, toasts, switches |
| `duration-slow` | 260 ms | Dialogs, sheets |
| `duration-slower` | 420 ms | Page-level reveals (hero, section headers) |

Entering things decelerate (`ease-enter`), leaving things accelerate (`ease-exit`). With "reduce motion" turned
on in the OS, every duration becomes 0 and Motion components skip their animation.
