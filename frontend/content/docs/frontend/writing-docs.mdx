<Steps>
  <Step>
    ### Create the file

    Add an `.mdx` file under `frontend/content/docs/` - in the folder of its section (`services/`, `frontend/`) or a
    new folder with its own `meta.json`.
  </Step>
  <Step>
    ### Add frontmatter

    ```mdx
    ---
    title: payment-service
    description: One sentence on what this page explains.
    icon: CreditCard
    ---
    ```

    `icon` is any [Lucide](https://lucide.dev/icons) icon name; it shows in the sidebar.
  </Step>
  <Step>
    ### List it in meta.json

    Add the file name (without `.mdx`) to `pages` in the folder's `meta.json`. The order there is the sidebar order.
  </Step>
  <Step>
    ### See it

    With `docker compose up` running, the page appears at `/v1/admin/docs-ui/...` and reloads on save.
  </Step>
</Steps>

## Which diagram to use

| You want to show | Use |
| --- | --- |
| Who calls whom, in order | `<SequenceDiagram>` - laid out for you from participants and steps |
| The whole system | `<SystemMap />` (edit `src/components/docs/diagrams/library.tsx`) |
| The states a transfer moves through | `<TransferStates />` |
| Any other flow (boxes and arrows) | `<Diagram>` with `<Box>` and `<Arrow>` |

<Callout type="error" title="No Mermaid">
  Mermaid is not used in these docs - its output doesn't match the design. Draw diagrams with the components
  above: pure SVG in the docs theme, with the main path animated.
</Callout>

A hand-drawn flow - boxes and right-angle arrows in viewBox coordinates. `flow` marks the main path (animated),
`dashed` an optional or async link, `cut` a failure branch; tones are `accent`, `success`, `warning`,
`danger` and `muted` (planned).

A sequence - no coordinates needed:

```mdx
<SequenceDiagram
  title="Transfer request" tag="POST /transfer"
  participants={[
    { id: "b", label: "Browser" },
    { id: "t", label: "transaction-svc", accent: true },
  ]}
  steps={[
    { from: "b", to: "t", label: "POST /transactions/transfer" },
    { from: "t", to: "t", label: "save PENDING" },
    { note: "amount >= threshold: wait for OTP", over: ["t"] },
    { from: "t", to: "b", label: "201 PENDING_VERIFICATION", reply: true },
  ]}
/>
```

## Other components

- `<Callout type="info|warn|error">` - a highlighted note.
- `<Tabs items={["Request", "Response"]}>` with `<Tab value="Request">` - side-by-side variants.
- `<Steps>` / `<Step>` - a numbered walkthrough, like the one at the top of this page.
