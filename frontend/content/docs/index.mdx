These notes document AegisBank as it is built: an event-driven banking system of Spring Boot microservices
with a Next.js frontend. Each page explains one part, why it works that way, and shows it as a diagram.

<Callout title="Private">
  This docs UI is not part of the customer site. In production it sits behind a password
  (`DOCS_AUTH_USER` / `DOCS_AUTH_PASSWORD`) and is hidden from search engines.
</Callout>
